# Zuri Market DevOps Capstone

## Project Overview

This project implements DevOps practices for the Zuri Market
frontend and backend applications.

## Objectives

- Containerize the frontend and backend applications with Docker.
- Automate testing and builds using GitHub Actions.
- Provision AWS infrastructure using Terraform.
- Deploy applications to Kubernetes.
- Monitor application performance using Prometheus and Grafana.
- Automate application health checks using Bash and cron.
- Apply security scanning and infrastructure best practices.

## Project Structure

- terraform/ - Infrastructure as Code
- kubernetes/ - Kubernetes manifests
- .github/workflows/ - CI/CD workflows
- monitoring/ - Monitoring configuration
- scripts/ - Automation scripts
- docs/ - Documentation and evidence
